# VEXORA Store

A responsive pre-launch storefront for VEXORA Store.

## Files
- `index.html` — page structure and content
- `style.css` — responsive visual design
- `script.js` — mobile navigation and current year

## Publish with GitHub Pages
1. Upload the contents of this folder to the **root** of your `vexora-store` repository.
2. Open the repository's **Settings**.
3. Open **Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch `main` and folder `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site.

## Important launch status
This version is a **pre-launch storefront**. It does not collect payments, create real orders, retrieve game account IDs, or fulfil top-ups. The Free Fire amount shown is a planned VEXORA selling price supplied by the owner, not a verified supplier quote or official publisher price.

To accept real payments, add a secure backend and payment-provider integration. Payment secret keys must stay server-side and must never be committed to GitHub or placed in browser JavaScript. Verify payment status server-side before fulfilling an order.

Game names are used only to identify intended catalogue categories. VEXORA is an independent storefront and is not affiliated with or endorsed by the game publishers.
